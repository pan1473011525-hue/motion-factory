# Motioner 阶段三实测问题修订执行方案（二）

> 状态：已由用户确认，实施与交付验证均已完成。
> 日期：2026-08-11
> 适用版本：Motioner 1.3.1
> 原则：仅调整 UI、布局、交互展示和保存生命周期；不修改项目文件结构、模板 Schema、动画计算或导出结果。

## 一、确认后的核心定义

### 1. 静默自动恢复

- 自动恢复采用 **8 秒防抖**。
- 自动恢复只写入独立恢复快照，不覆盖用户显式保存的项目文件。
- 自动恢复成功不显示“保存中 / 已保存”提示，也不把项目标记为已保存。
- 自动恢复失败仍需给出明确错误反馈。
- 正常关闭后清理恢复快照；异常退出保留恢复快照。
- 从恢复快照恢复的项目仍视为“有未保存修改”。

### 2. 退出询问

- 仅在存在未保存修改时询问。
- 提供“保存并退出 / 不保存 / 取消”三种选择。
- “保存并退出”使用当前项目路径；无路径时进入“另存为”。
- 保存取消或失败时取消退出。
- 没有未保存修改时直接退出。

### 3. 数字输入显示

- 数字输入框内只显示数字，不显示 `%`、`°`、`×` 等单位。
- 字段语义由行标签表达，不改变内部数值范围、存储单位和计算逻辑。
- 旋转、透明度、位置、尺寸、动效强度等同类控件统一处理。

### 4. 下拉控件统一

- 不保留原生 `<select>` 与自定义菜单并存的情况。
- 应用内现有下拉选择全部迁移为同一套 `Select/Listbox` 组件，包括：
  - 顶栏清晰度、画面方向、帧率、导出格式；
  - 预览背景、预览缩放；
  - 属性面板中的枚举字段、动效预设、场景、字体、动画、导出设置；
  - CSV 批量映射等次级界面。
- 菜单通过 Portal + fixed 定位脱离面板裁剪和布局流；优先向下展开，空间不足时保持在可视区域内。
- 选项完整显示，不压缩，不撑开顶栏，不挤压画布。
- 当前值同时使用高亮与勾选表达。
- 支持方向键、Home/End、Enter/Space、Escape、Tab 和点击外部关闭。
- 提供清晰的 hover、focus-visible、active、disabled 状态及可访问名称。
