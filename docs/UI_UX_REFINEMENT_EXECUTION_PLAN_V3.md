# Motioner 阶段三实测问题修订执行方案（三）

> 状态：已按用户反馈实施，全部验证与安装包交付已完成。
> 日期：2026-08-11
> 适用版本：Motioner 1.3.1
> 原则：仅调整 UI、布局、交互展示和关闭生命周期；不修改项目文件结构、模板 Schema、动画计算或导出结果。

## 一、确认后的问题与处理定义

### 1. 顶栏输出控件

- 清晰度与横竖屏拆为两个独立的焦点容器，点击清晰度时不得连带高亮画面方向。
- 全应用继续使用同一套 `Select/Listbox`，不引入第二种下拉样式。
- 菜单宽度按真实文字宽度计算，在触发器中心下方锚定，并限制在视口内。
- 选项文本视觉居中；勾选列和尾部占位对称，避免勾选图标把文字推偏。

### 2. 右侧检查器排版

- 仅含短枚举值的字段改为“左侧字段名 + 右侧下拉控件”的紧凑单行布局。
- 帮助文字独占下一行，避免字段语义被压缩。
- 不改变字段值、枚举选项和写入逻辑。

### 3. 动效操作区

- 每个入场、持续、退场动效分组底部设置独立动作区。
- 动作区使用上分隔线和额外间距，与滑块及数字输入形成明确层级。
- “重置”为次级动作，“清除”为危险动作；保持可读尺寸，不做突兀的大按钮。

### 4. 品牌与项目名称

- 左上品牌仅保留应用图标和 `Motioner`，去掉版本号和“快速制作 / 专业制作”描述。
- 项目名称支持直接点击编辑；Enter 或失焦提交，Escape 取消，空名称不提交。
- 重命名进入现有 dirty、撤销和保存流程，不新增项目字段。

### 5. 关闭提示

- dirty 项目退出时使用 Motioner 自身视觉语言的模态弹窗，提供“取消 / 不保存 / 保存并退出”。
- 保持原有主进程关闭拦截和保存握手；保存取消、保存失败或弹窗超时均安全取消退出。
- 无未保存修改时仍直接退出。

### 6. 顶栏按钮与全局提示

- 顶栏模式切换、文件动作、快捷键、输出设置和导出按钮统一垂直尺寸、边框、圆角及间距节奏。
- 全局按钮通过延迟悬停提示展示名称或功能；优先读取 `data-tooltip` / `aria-label` / `title`。
- 下拉菜单展开时隐藏全局提示，避免提示与菜单重叠。

### 7. 全局滑块双击重置

- 所有已声明默认值的滑块支持双击恢复默认值。
- 模板参数从 manifest 默认值恢复；组件参数从组件定义默认值恢复；时间、变换、动效与模组外观使用各自已有默认值。
- 数字输入框和现有重置按钮行为保持不变。
