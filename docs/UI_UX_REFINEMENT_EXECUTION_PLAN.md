# Motioner UI/UX 阶段三实测问题修订施工方案

> 状态：已实施、验证并完成交付
> 确认日期：2026-08-11
> 适用版本：Motioner 1.3.1 之后的下一次本地交付
> 视觉依据：`docs/ui-redesign-plan.md`、`docs/design-reference/`、阶段一至阶段三完成报告，以及本轮 7 张实测截图

## 1. 目标与边界

本轮不是重新设计整套产品，而是在已通过验收的三阶段 UI 架构上修复实测暴露的效率和一致性问题。最终目标是：模板模式只保留一套明确的预览控制；输出规格遵循“清晰度档位 + 横竖方向”；右侧属性采用专业创作工具的紧凑数值行；动效通过拖放应用；时间线工具与快捷键形成稳定、可自定义的桌面编辑语法。

继续遵守以下边界：

- 不改变 Remotion 帧驱动动画计算。
- 不改变现有导出文件类型、编码预设、渲染队列和媒体验证逻辑。
- 不把自由编排扩张为完整非线性剪辑软件。
- 不引入第二套图标库，继续使用 `lucide-react`。
- 不修改现有模板字段 Schema；模组底色使用统一的项目级外观配置注入模板运行时。
- 不提交用户提供且当前未跟踪的 `docs/CODEX_HANDOFF_PROMPT.md`、`docs/design-reference/`、`docs/ui-redesign-plan.md`。

### 唯一获准的数据契约扩展

项目新增可选的 `templateAppearance`：

- `surfaceColor`：动画模组内部底色。
- `surfaceOpacity`：模组底色不透明度，范围 0–1。
- `surfaceTone`：`auto | dark | light`，默认 `auto`，用于保证前景文字和分隔线对比度。

旧项目缺少该字段时使用兼容默认值，保持当前模板暗色外观。该配置随项目保存并进入模板预览和真实导出；模组外围仍保持透明。项目迁移必须有单测，不能破坏 v1/v2 项目读取。

## 2. 批次 A：模板播放、模组外观、输出规格

### A1. 模板播放控制单一化

- 模板模式关闭 Remotion Player 原生 controls、click-to-toggle 和循环播放。
- 模板画布顶部不再显示运输控制，底部简化时间线成为唯一播放控制区。
- 点击模板预览区域时从首帧完整播放一次；播放结束停在末帧。
- 自由编排画布点击仍用于选择与拖动节点，不触发播放。
- 底部保留播放/暂停、从头预览、拖动寻帧、时间码与帧数。

验收：模板画面无原生播放覆盖层和原生进度条；任意时刻点击画面都会从首帧播放一次；底部控件行为不回退。

### A2. 动画模组底色

右侧模板样式区增加“模组外观”，预设：

- 原始样式
- 透明
- 纯黑 `#000000`
- 深灰 `#111418`
- 冷蓝黑 `#101A2A`
- 暖灰黑 `#261D1A`
- 中性灰 `#2A2D32`
- 柔和浅色 `#F2F3F5`
- 纯白 `#FFFFFF`
- 自定义

控件：预设色块、取色器、HEX 输入、最近使用颜色、不透明度滑块 + 数字输入、恢复默认。

运行时规则：

- 修改的是模板内部模组表面，不是编辑器棋盘格/审看底。
- 背景为浅色时自动切换深色正文、次级文字和分隔线；深色背景保持浅色前景。
- 强调色沿用模板原有参数，不被表面预设覆盖。
- 半透明表面在透明输出中保留 alpha；H.264 审看底逻辑不变。
- 模板预览与导出复用同一外观上下文。

验收：至少用数据图表、信息卡、媒体类三种模板验证深色、浅色、透明、50% 不透明四类结果，文字均可读，导出与预览一致。

### A3. 清晰度档位与横竖屏

顶栏只提供：

- 清晰度：1K / 2K / 4K。
- 方向：横屏 / 竖屏。

映射：

| 档位 | 横屏 | 竖屏 |
|---|---:|---:|
| 1K | 1920×1080 | 1080×1920 |
| 2K | 2560×1440 | 1440×2560 |
| 4K | 3840×2160 | 2160×3840 |

导出设置在相同档位与方向之外增加“自定义”。只有选择自定义时显示宽高输入；输入继续在 blur/Enter 时提交并自动偶数化。

验收：顶栏不能输入任意尺寸；横竖切换保持档位；自定义尺寸只在导出设置出现；预览画幅和真实导出尺寸一致。

## 3. 批次 B：紧凑属性控件与检查器信息架构

### B1. 可复用紧凑数值控件

新增统一控件：

- `CompactNumberControl`：标签 + 可选滑块 + 数字输入 + 单位 + 重置。
- `CompactXYControl`：X/Y 紧凑双值行。
- `CompactSizeControl`：宽/高双值行 + 比例锁定。

规则：只有明确最小值和最大值的连续数值使用滑块；文本、路径、颜色 HEX 和自定义分辨率不强套滑块。所有数值使用 tabular nums，输入变化不得推动按钮或面板布局。

### B2. 全面替换浪费空间的数值阵列

首批覆盖：位置、尺寸、旋转、透明度、图层开始帧/持续帧、入退场帧数、整体与三通道动效强度、模板中具有 min/max 的数值字段、项目时长和模组底色不透明度。

### B3. 右侧检查器拆分

自由编排右侧永久显示：`基础设置 | 动效设置`。

基础设置顺序：图层状态 → 变换 → 组件参数 → 布局/样式 → 时间 → 场景 → 只读信息。模板快照移动到底部并默认折叠。

动效设置按入场、持续、退场分组；每组显示当前预设、帧数/强度、替换、清除和重置。保持每阶段一个动效，不引入动效栈。

验收：右侧不再出现图 6 式大面积双列输入框；图 7 式紧凑属性行成为数值参数的统一语法；切换 Tab 不改变面板宽度和底部操作位置。

## 4. 批次 C：动效拖放与中间工具栏

### C1. 动效库改为拖放入口

- 移除动效卡片勾选框、阶段按钮和点击应用行为。
- “无动效”不再作为普通卡片；清除操作进入右侧动效设置。
- 卡片只提供名称、说明、相位能力和拖拽把手。
- 拖到画布组件时显示“入场 / 持续 / 退场”三个落点，只允许预设支持的相位。
- 时间线素材条继续使用左/中/右相位落点。

### C2. 中间栏统一

采用固定 30px 工具按钮和 Lucide 图标，按以下顺序分组：

1. 首帧、上一帧、播放/暂停、下一帧、末帧。
2. 标记、导出分段点。
3. 复制、置顶、上移、下移、置底。
4. 波纹删除、普通删除。
5. 最右侧固定时间码。

标记与分段使用纯图标按钮并保留 `title`、`aria-label`；层数与动效关键点说明进入状态区；删除操作与普通操作之间有明确分组间距。

验收：同一栏所有按钮尺寸、边框、激活和禁用状态一致；长图层名、层数变化和窗口宽度变化不导致工具跳动。

## 5. 批次 D：快捷键系统

新增集中命令表与用户键位映射，默认：

| 操作 | 默认快捷键 |
|---|---|
| 播放/暂停 | Space |
| 上一帧/下一帧 | ← / → |
| 时间线开头/结尾 | ⌘← / ⌘→ |
| 添加标记 | M |
| 添加导出分段点 | Shift+M |
| 复制图层 | ⌘D |
| 删除图层 | Delete / Backspace |
| 波纹删除 | Shift+Delete |
| 保存 | ⌘S |
| 撤销/重做 | ⌘Z / ⇧⌘Z |
| 微移组件 | ⌥+方向键 |
| 大步微移组件 | ⇧⌥+方向键 |

快捷键设置提供命令搜索、录入、冲突检测、清除、单项重置、全部重置。用户键位存入 `localStorage`，不写入项目文件。输入框、文本框、下拉框和 contenteditable 获得焦点时不得触发编辑命令。

验收：所有默认键位可用；冲突不能静默覆盖；自定义键位重启应用后保留；方向键逐帧与画布节点微移不冲突。

## 6. 分批验证、文档与交付

每个批次完成后至少运行受影响的单测与 `pnpm check`；最终必须完成：

1. `pnpm check` 全绿。
2. `pnpm test:exports`，覆盖模板半透明表面及横竖屏输出。
3. 启动真实应用，检查模板/自由编排、横屏/竖屏、深浅表面、长文本、空状态、禁用状态和快捷键设置。
4. 保存阶段三修订截图到新目录，不覆盖既有阶段截图。
5. 更新 `docs/IMPROVEMENT_ROADMAP.md`、`docs/HANDOFF.md`、`docs/阶段三完成报告.md`。
6. `pnpm package:dmg`，执行 `hdiutil verify`，更新 `release/SHA256SUMS.txt` 与完整性清单。
7. 清理中间产物，只保留交付 DMG、校验和与完整性清单。
8. Git 仅提交本轮受控文件；提交前再次确认用户参考文件未被纳入。
