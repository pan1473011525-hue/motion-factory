# Motioner 1.3.1 用户手册

Motioner 是 Apple Silicon macOS 与 Windows x64 上的本地动效工具。它不需要网络、账号或云服务：既能选择模板后填写参数，也能从组件库自由编排图层；设定画布与时长后，即可把透明视频直接拖入剪辑软件。

## 1. 安装与首次启动

1. 打开 `Motioner-1.3.1-arm64.dmg`，把 Motioner 拖入“应用程序”。
2. 当前构建未做 Apple 公证或 Windows 代码签名，仅供测试和自用。macOS 首次阻止启动时可在 Finder 中右键 Motioner 后选择“打开”；Windows 出现 SmartScreen 时应先核对安装包来源和 SHA-256，再决定是否运行。
3. 应用内置 Headless Chrome、FFmpeg、FFprobe 与模板 bundle；首次导出不下载组件。

建议环境：Apple Silicon + macOS 14 或更高，或 Windows 10/11 x64；至少 16 GB 内存。4K ProRes 会产生较大的临时文件，导出前应保留充足空间。

## 2. 工作台

界面保持三列工作台：

- 左侧资源库：模板模式显示模板库；自由编排模式显示组件与动效库。
- 中央画布：播放、暂停、逐帧、缩放、背景与安全区；自由编排模式下还显示图层选框和时间轴。
- 顶栏输出快捷区：点击分辨率、帧率、秒数或格式即可直接修改；右侧检查器仍保留自定义尺寸、重名策略等完整输出设置。
- 右侧检查器：模板模式编辑模板参数；自由编排模式编辑选中图层、场景、画布与导出。

模板卡片上的星标用于收藏；选择模板后会加载该模板的默认值。模板版本随项目保存，旧项目打开时会自动执行兼容迁移。

## 3. 模板与自由编排

工具栏的“模板 / 自由编排”用于切换工作方式：

- 模板模式适合最快交付：选择模板、填参数、选素材后直接导出。
- 第一次进入自由编排时，当前模板会成为一个全画幅“模板场景”图层，参数以快照保存。它可以继续移动、缩放、定时和添加图层动效。
- 再次切换模式不会删除任一侧内容：模板参数与 Composer 场景会同时保存在项目中。
- 自由编排左侧包含 21 个基础组件：文字、图形、数据、媒体和常用版式（含列表逐项、卡片堆叠、骨架屏、SVG描边、里程表数字、动效动画）。点击组件即可在画布中央创建图层。
- “动效”页包含淡入、升起、落下、左右滑入、缩放、弹入、擦除、模糊、漂浮、脉冲、漂移、旋转和呼吸等预设。选中图层后点击“入场 / 退场 / 循环”即可勾选，再点一次可移除；也可把动效卡拖到时间线素材条，落在左、中、右区域分别应用为入场、循环或退场。

画布中可拖动图层，使用八个控制点缩放；方向键微调，按住 Shift 加速微调，按住 Option 临时绕过吸附。右侧可精确输入 X、Y、宽、高、旋转和透明度。图层时间轴支持拖动片段、修剪首尾、复制、删除、显隐、锁定和调整层级；点击时间尺或任意轨道可跳到对应帧，按住拖动可连续预览。

#### 转场遮罩模板用法

“转场”分类下的模板（百叶窗、时钟、光圈、墨染、撕裂、线性/径向/锥形渐变）输出的是黑白 alpha 遮罩视频：白色区域不透明、黑色区域透明、过渡边缘半透明。配合剪辑软件的轨道遮罩功能即可实现素材间的无缝转场：

1. 在时间线上把“前一段素材”放在下层轨道，“后一段素材”放在其上层相邻轨道；
2. 把导出的转场遮罩视频放在后一段素材上方的遮罩轨道，与两段素材的切换点对齐；
3. 对后一段素材添加“轨道遮罩键 / Track Matte Key”，遮罩选择该遮罩轨道、类型选 Alpha；
4. 调整遮罩片段的时长与素材切换时长一致即可。

遮罩动画在视频开头约 2 秒内完成，之后保持全白；导出时长即为转场时长。

## 4. 项目操作

- `⌘N`：新建项目。
- `⌘O`：打开 `.mfxproj`。
- `⌘S`：保存。
- `⇧⌘S`：另存为。
- `⌘Z` / `⇧⌘Z`：撤销 / 重做参数修改。

`.mfxproj` 是可读 JSON 文件，保存模板参数、Composer 场景和素材路径，不把素材本体塞进项目。已保存项目会自动保存到原文件；未命名项目写入恢复快照。下次启动会优先给出恢复入口，否则自动打开最近一个仍存在的项目。1.2 及更早项目会自动升级为 v2 格式并保持模板模式。

重要项目交付前使用“收集素材”。Motioner 会把素材复制到指定 `.assets` 文件夹，更新项目引用并写入 SHA-256 指纹。随后再保存项目，项目与素材即可一起移动。

## 5. 内容、数据与素材

右侧字段由模板 Schema 自动生成。超长文字、非法数值、数组数量不足或缺少必选媒体时，导出会被阻止并显示具体原因。

数据数组支持：

- 直接编辑单元格。
- 从 Numbers 或 Excel 复制后粘贴。
- 导入 CSV；标题可使用字段 key 或界面中的中文列名。
- 拖动行、上移、下移、删除。

CSV 批量生成最多读取 100 行。导入后会先显示表头、前几行样例、自动推断的列映射和逐行错误；可把任意列映射到模板字段或设为忽略。文件名支持 `{{project}}`、`{{index}}`、`{{name}}` 与任意 CSV 列名令牌。确认后再一次性加入顺序队列。

媒体字段支持 PNG、JPEG、WebP、GIF、TIFF、SVG、MOV、MP4、M4V 与 WebM。图文素材卡还可设置：

- `cover`、`contain` 或拉伸填充。
- 水平/垂直焦点。
- 缩放与圆角。
- 视频入点、出点、0.25×–4× 播放速度，以及单次结束隐藏、尾帧持有或片段循环。

导入图片/视频后，Motioner 会在本地缓存缩略图；视频另建 H.264 代理供编辑预览，最终导出仍读取原文件。移动或删除源文件后，可“重链文件”批量选取替代项，或“扫描文件夹”按文件名递归匹配；“收集素材”则把项目依赖固定到同一资产目录。

字体区可导入 OTF、TTF、WOFF 或 WOFF2 作为当前项目字体，并保留系统无衬线、衬线和等宽回退。导入前请确认字体许可允许用于成片。

## 6. 画布、时长和动效

预设画布包括 1080p 横屏、4K 横屏、1080p 竖屏与 1080 方形；自定义宽高必须为偶数，范围为 320×240 至 8192×8192。

帧率以分数保存，支持 23.976、24、25、29.97、30、50、59.94 与 60 fps。修改秒数后，界面会显示实际总帧数与帧对齐后的时长。

全局动效设置包括：

- 速度：0.5×–2×。
- 入场/退场边缘：6–90 帧。
- 减少动效：保留淡入淡出，去除明显位移、逐项错峰和数字滚动。

参数预设会保存当前模板参数、画布、动效与导出格式，适合重复制作同一栏目。可把所有预设导出为 JSON，在重装或另一份开发构建中重新导入。

自由编排图层另有独立时序和动效。改变项目帧率时，Motioner 会按比例换算图层的开始帧与持续帧，以保持时间长度；缩短项目时长会自动夹紧越界图层。图片和视频组件使用项目素材清单，视频层当前按静音素材处理。

## 7. 预览

自由编排模式可按空格播放/暂停，也可使用画布工具栏或时间线左上角的播放按钮。点击时间尺或轨道会显示对应时间画面；按住并左右拖动可连续寻帧。若从播放状态开始拖动，拖动期间会暂停，松手后继续播放。中央工具栏另提供首帧、末帧、前后 1 帧；缩放可选 25%、50% 和 100%。在输入框、下拉菜单和按钮上操作时，空格保留给当前控件。

透明背景可切换为棋盘格、黑、白、灰或自选截图。安全区只影响预览，不进入成片。H.264 审看版会自动使用深色底，因为 H.264 不保留 alpha。

预览与导出使用同一 Remotion 组件；动画只由当前帧、项目参数与素材决定，拖动到任一帧都能得到稳定画面。

## 8. 导出格式

| 格式 | 用途 | 透明 | 典型后续 |
|---|---|---:|---|
| ProRes 4444 MOV | 默认母版 | 是 | FCP、Premiere、Resolve 时间线 |
| ProRes 4444 XQ MOV | 更高数据率母版 | 是 | 高质量合成与调色 |
| PNG RGBA 序列 | 单帧/序列交换 | 是 | 合成软件、极端兼容场景 |
| H.264 MP4 审看版 | 快速审片 | 否 | 发给他人、快速确认 |

导出前 Motioner 会估算大小并检查目标磁盘，至少保留估算值的 115%。任务在独立进程中顺序执行，编辑器仍可继续操作。队列支持取消和失败重试；取消活动任务后会清除临时产物，后续任务继续执行。

输出重名时可选择自动追加 `-v2` 版本号、验证成功后替换旧文件，或直接跳过。文件先渲染到同目录的隐藏临时路径。只有通过 FFprobe 元数据断言（包括 Rec.709 三项色彩标记）和 FFmpeg 全片解码后，才会原子改名为最终文件。成功视频旁会生成同名 `.motioner.json`；PNG 文件夹中会生成 `motioner-export-report.json`。

报告包含模板、画布、帧率、帧数、编码参数、验证摘要、文件大小和时间。任务完成后可点“在 Finder 中显示”。

## 9. 常见问题

### 导出按钮不可用

先看右侧红色校验信息。常见原因是必填文字为空、数据行不足、时长小于模板最低值、媒体槽未选择或源文件已经移动。

### 29.97/59.94 看起来不是整数

这是正常的广播分数帧率，项目分别保存为 `30000/1001` 与 `60000/1001`。Motioner 按帧数导出，并在完成后检查流的分数帧率与总帧数。

### 导出被取消或崩溃后留下坏文件吗

不会把临时文件冒充成最终成片。异常和取消会清理 `.motioner-*` 临时路径；若目标名称已经存在，Motioner 不会静默覆盖有效成片。

### 去哪里看日志

Finder 选择“前往文件夹”，输入：

```text
~/Library/Application Support/Motioner/logs/motioner.log
```

恢复快照位于同一目录下的 `recovery/active.mfxrecovery`。定位问题时保留项目、导出报告与日志即可。

## 10. 当前边界

Motioner 1.3 提供图层时间轴，但不替代剪辑软件：不包含音频混合、镜头剪辑、任意关键帧曲线、账号、云渲染、模板商店或第三方脚本运行。新增内置模板仍采用脚手架生成、源码集成并重新构建应用，具体见《新增模板开发指南》；常用自由组合则直接使用组件与动效库，无需重新开发模板。
