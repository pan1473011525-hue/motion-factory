## 3. 版本能力验收

### 1.0.1 可靠性

- 缺失素材支持多文件重链或递归扫描文件夹按文件名匹配。
- 输出重名支持自动 `-v2`、验证成功后安全替换、直接跳过。
- 视频写入并验证 Rec.709 `color_space`、`color_primaries`、`color_transfer`；H.264 同时写入 VUI。
- 增加透明通道测试卡；半透明、模糊、阴影、细线和渐变边缘可直接输出测试。
- Renderer 拆出模板库、批量面板和导出队列模块；主应用职责缩小。
- 打包后的 `.app` 可在无开发环境下独立完成 H.264 导出与报告生成。

### 1.1 效率工作流

- 项目可导入 OTF/TTF/WOFF/WOFF2，并保留系统无衬线、衬线、等宽回退。
- 模板脚手架可生成 Manifest/组件并自动写入 catalog/runtime 注册点。
- CSV 先预览表头与样例，再自动/手工列映射、预览命名、显示逐行错误后批量入队。
- 媒体导入生成缩略图和 H.264 代理；最终导出仍读取原始素材。
- 视频支持入点、出点、0.25×–4×、单次隐藏、尾帧持有和循环。
- 参数预设可导出/导入版本化 JSON 集合。

### 1.2 模板与画幅

- 模板从 12 个扩展到 22 个。
- 新增：透明测试卡、路线地图、多系列折线、堆叠柱状、新闻标题、体育比分、画面标注、素材轮播、前后对照、自适应分屏。
- 每个模板保留三套样式预设，并声明 16:9、9:16、1:1 与自定义画幅。
- 修正大数字模板硬编码尺寸；竖屏不再裁切数值与后缀。

### 1.3 自由编排与正式图标

- 工具栏新增模板/自由编排切换；模板参数和 Composer 场景同时保存，切换不会丢失工作。
- 当前模板可冻结为全画幅模板场景节点，继续移动、缩放、定时和应用图层动效。
- 组件库提供 15 个基础组件；动效库提供 16 个入场、退场和持续预设。
- 画布支持拖动、八向缩放、网格/磁吸、键盘微调、显隐与锁定；时间轴支持移动、修剪、复制、删除和层级调整。
- 节点检查器覆盖变换、内容、样式、媒体、时序和动效；预览与最终渲染复用同一 Composer Remotion 运行时。
- 项目格式升级为 v2，v1 项目与恢复快照自动迁移；旧项目默认保持模板模式。
- Motioner 正式 PNG 已生成 1024×1024 应用资源，并由打包器生成 1,467,478 字节 `icon.icns`。

## 6. 安全与持久化

- Renderer 保持 sandbox、Node 关闭与 contextBridge 白名单。
- IPC 请求由 Zod 合同解析；模板没有文件系统、shell 或网络能力。
- 项目文件对旧版自动补齐 typography、exportOptions、editorMode 与 composition；模板字段按逐版迁移链升级。
- Composer 节点 props、归一化变换、时序、动效和素材引用均通过 Zod 与主进程双重校验；场景最多 200 个节点。
- 导出在隐藏临时路径完成，校验成功才提升为最终文件；覆盖策略先备份旧目标，提升失败时恢复。
- 项目素材服务器仅绑定 `127.0.0.1`，只按资产 ID 暴露当前项目白名单文件。

## 8. 已知边界

- 不包含音频混合、镜头剪辑、任意关键帧曲线、账号、云渲染或模板商店。
- Composer 视频组件当前按静音图层处理；音频仍由后续剪辑软件完成。
- 1.x 新模板使用脚手架后源码集成并重新打包；不运行第三方模板脚本。
- UI 保持克制的三栏桌面工作台，没有引入不必要的云服务或大型状态框架。

结论：Motioner 1.3.0 已完整实现既定规划与自由编排扩展，并达到可交付个人 Apple Silicon macOS 安装包的验收标准。
