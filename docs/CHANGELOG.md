# Motioner 更新记录

## 1.3.1 · 2026-08-10

- 自由编排支持空格播放/暂停，画布与时间线增加状态同步的显式播放按钮。
- 时间尺和每条图层轨道支持点击寻帧、按住拖动预览轴；播放中寻帧会暂时暂停并在松手后继续。
- 动效卡支持阶段勾选与再次点击移除；也可拖到时间线素材条的左、中、右区域应用为入场、循环或退场。
- 顶栏原输出参数预览升级为快捷设置，可直接修改分辨率、帧率、时长和导出格式。
- 增加时间轴指针映射、边界夹紧与动效拖放阶段判断测试。

## 1.3.0 · 2026-08-10

- 新增“模板 / 自由编排”双模式，原模板填参工作流保持不变；切换自由编排时可把当前模板冻结为场景图层。
- 新增 15 个基础组件与 16 个入场、退场、持续动效预设，全部按当前帧确定性计算。
- 新增可交互画布：选择、拖动、八向缩放、键盘微调、网格与磁吸、图层锁定和显隐。
- 新增图层时间轴：移动、修剪、复制、删除和层级顺序调整；检查器可编辑变换、内容、样式、媒体、时序和动效。
- 项目格式升级至 v2；v1 项目文件与恢复快照会自动迁移为兼容项目。
- 预览与导出继续复用同一 Remotion Composition；增加 Composer 三画幅静帧回归和实际 H.264 场景导出。
- 接入 Motioner 正式图标，覆盖应用工具栏、macOS 应用包、Dock 与 DMG。

## 1.2.0 · 2026-08-10

- 模板从 12 个扩展至 22 个，新增透明测试卡、路线地图、多系列折线、堆叠柱、新闻标题、体育比分、画面标注、素材轮播、前后对照和自适应分屏。
- 全模板加入横屏、竖屏、方形与自定义画幅能力声明，并对 66 张三画幅基准静帧执行实际渲染。
- 增加自定义字体、模板脚手架、参数预设 JSON 导入/导出。
- CSV 批量流程升级为导入预览、自动列映射、手工修正、命名规则与逐行错误反馈。
- 素材导入生成缩略图/视频代理；视频支持入点、出点、倍速、单次、持有和循环播放。
- 增加文件/文件夹重链、输出重名策略与打包应用无界面 E2E。
- 视频完成后写入并验证 Rec.709 色彩空间、色彩原色和传递函数三项元数据。
