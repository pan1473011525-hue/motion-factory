Motioner UI 重构计划 v1.0

项目目标

Motioner 是一个桌面端动效视频制作软件。

当前版本已经具备：

* 模板快速生成
* 自由编排
* 组件系统
* 时间线
* 属性编辑
* 视频导出

本次任务：

仅进行 UI/UX 重构。

禁止：

* 修改数据结构
* 修改动画逻辑
* 修改导出逻辑
* 修改文件格式
* 删除已有功能

目标：

打造类似：

* Apple Motion
* Figma
* Final Cut Pro
* After Effects

的专业桌面级创作软件体验。

4. 固定布局规则

所有区域：

固定。

禁止：

以下情况导致 UI 移动：

* 文本长度变化
* 数量变化
* 内容变化

处理优先级：

1. 折叠
2. 滚动
3. 省略

禁止：

自动挤压其他组件。

* 面板展开
* Tab切换
* 按钮状态

不要：

花哨。

保持：

专业工具感。
